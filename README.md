# 아트캠퍼스 메타버스

3D 학원 건물을 캐릭터로 돌아다니며 책장에서 자료를 열고 받는 내부 직원용 웹 월드입니다.

## 자료 바꾸는 법 (코드 수정 없음)

1. 구글 시트 첫 줄에 머리글을 이 순서로 적습니다.

   | 강의실 | 책장 | 자료명 | 유형 | 링크 | 등록일 | 설명 |
   |---|---|---|---|---|---|---|

   - 강의실: `로비` · `게임원화` · `웹툰` · `웹소설`
   - 책장: 같은 이름끼리 한 책장에 꽂힘 (방마다 4개, 로비 1개)
   - 유형: PDF · 이미지 · 영상 · 문서 · 시트 · 원본 · 압축 · 링크
   - 링크: 구글 드라이브 공유 링크 → 열기·다운로드 주소 자동 변환
   - 등록일: 7일 이내면 NEW 표시
2. 시트에서 **파일 → 공유 → 웹에 게시 → (해당 시트) → 쉼표로 구분된 값(.csv) → 게시**를 누르고 주소를 복사합니다.
3. 이 저장소의 `config.json`을 GitHub에서 열고 연필 버튼으로 편집해 주소를 넣고 저장(Commit)합니다.

   ```json
   { "sheetCsvUrl": "https://docs.google.com/spreadsheets/d/e/.../pub?output=csv" }
   ```

4. 1~2분 뒤부터 모든 직원이 접속(새로고침)할 때 시트 내용이 책장에 반영됩니다. 이후에는 시트만 고치면 됩니다. 구글의 게시 캐시 때문에 시트 수정이 반영되기까지 최대 5분쯤 걸릴 수 있습니다.

## 함께 접속 · 채팅 (Firebase)

- `config.json`의 `firebase` 값이 비어 있으면 혼자 둘러보는 모드로 열립니다.
- 값을 채우면 직원 명단에 있는 구글 계정만 로그인할 수 있고, 다른 직원 캐릭터·말풍선·전체/방/1:1 채팅이 켜집니다.
- 데이터베이스 보안 규칙은 `database.rules.json`에 있습니다. 직원 명단은 이 저장소가 아니라 Firebase 안에만 둡니다.

## 보안 메모

- 이 사이트 주소를 아는 사람은 누구나 자료 **목록**을 볼 수 있습니다. 실제 파일은 구글 드라이브 권한이 지킵니다.
- 내부 자료는 드라이브에서 "링크가 있는 모든 사용자" 대신 직원 계정(또는 조직)으로만 공유하면, 권한 없는 사람은 열기를 눌러도 파일을 볼 수 없습니다.
